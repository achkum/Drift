# Drift

Drift shows how your social media feeds slowly change what you watch: what the apps **serve** you versus what you **choose**. Upload your own data export from YouTube, TikTok or Instagram, and all analysis runs in your browser. Nothing is uploaded.

## Run it

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Checks

```bash
npm run typecheck && npm run lint && npm test
```

See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) for how the code is organised.
